Update the animejs import and usage to work with v3 API:

**Current (line 4):**
```typescript

```

**Change to:**
```typescript
import anime from 'animejs';
```

**Current (lines 105-112):**
```typescript
const animeInstance = (anime.default || anime);
animeInstance({
  targets: '.gantt-dependency-line',
  strokeDashoffset: [animeInstance.setDashoffset, 0],
  easing: 'easeInOutQuad',
  duration: 1000,
  delay: 200,
});
```

**Change to:**
```typescript
anime({
  targets: '.gantt-dependency-line',
  strokeDashoffset: [anime.setDashoffset, 0],
  easing: 'easeInOutQuad',
  duration: 1000,
  delay: 200,
});
```

This uses the v3 default export directly without namespace workaround. The v3 API provides `anime()` as the main function and `anime.setDashoffset` as a helper for SVG path length calculation.
