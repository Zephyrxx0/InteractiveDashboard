**Change to - v4 API with strokeDashoffset:**
```typescript
// Get all dependency line paths
const paths = document.querySelectorAll('.gantt-dependency-line');
if (!paths.length) return;

// Calculate total path length for each path and set initial dashoffset
paths.forEach((path) => {
  const length = (path as SVGPathElement).getTotalLength();
  (path as SVGPathElement).style.strokeDasharray = `${length}`;
  (path as SVGPathElement).style.strokeDashoffset = `${length}`;
});

// Animate strokeDashoffset from full length to 0 (drawing effect)
animate('.gantt-dependency-line', {
  strokeDashoffset: [
    (el: HTMLElement) => (el as SVGPathElement).getTotalLength(),
    0
  ],
  easing: 'inOutQuad',
  duration: 1000,
  delay: 200,
});
```

**Why this approach:**
1. Uses v4 named export `animate()` - no default export issues
2. Manual strokeDashoffset setup (v3's `anime.setDashoffset` doesn't exist in v4)
3. Function-based from value: `(el) => el.getTotalLength()` calculates per-element
4. Maintains same visual effect: line "draws" from start to end over 1000ms
5. No need for `createDrawable()` - direct strokeDashoffset animation is simpler

**Alternative (if user prefers their exact pattern):**
If you want to keep the namespace import with fallback checking:
```typescript
import * as anime from 'animejs';

// In useEffect:
const animeInstance = (anime as any).default ?? anime.animate ?? anime;
if (typeof animeInstance !== 'function') {
  console.error('Anime import is not a function:', animeInstance);
  return;
}

// Calculate and set dasharray/offset before animating
const paths = document.querySelectorAll('.gantt-dependency-line');
paths.forEach((path) => {
  const length = (path as SVGPathElement).getTotalLength();
  (path as SVGPathElement).style.strokeDasharray = `${length}`;
  (path as SVGPathElement).style.strokeDashoffset = `${length}`;
});

// Use animeInstance (which is anime.animate in v4)
animeInstance({
  targets: '.gantt-dependency-line',
  strokeDashoffset: [
    (el: any) => (el as SVGPathElement).getTotalLength(),
    0
  ],
  easing: 'inOutQuad',

  delay: 200,
});
```

**Recommended: Use the first approach (clean v4 named import).** The namespace import is a v3 workaround that's not needed in v4.

<notes>
**Why v4 instead of downgrading to v3:**
- v4 is already installed (4.3.6)
- v4 migration is forward-compatible
- Downgrade would require package changes and potential breaking changes later
- v4 API is cleaner with named exports (ES modules standard)

**Key v4 API differences from v3:**
- v3: `import anime from 'animejs'; anime({ ... }); anime.setDashoffset`
- v4: `import { animate } from 'animejs'; animate({ ... })`
- v4 removed `setDashoffset` helper - must calculate getTotalLength() manually
- v4 added `createDrawable()` for advanced SVG line drawing, but direct strokeDashoffset works fine

**Migration guide:** https://github.com/juliangarnier/anime/wiki/Migrating-from-v3-to-v4
</notes>
